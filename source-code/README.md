# 명디지털포렌식센터 홈페이지 초안

메인 페이지와 회사 소개, 디지털포렌식, 침해사고 조사, 솔루션 및 스토리지의 4개 서브페이지로 구성한 정적 홈페이지입니다.

## 실행

Node.js만 있으면 됩니다. 별도 패키지 설치는 필요하지 않습니다.

```powershell
cd D:\Macro\develop\homepage\mdfc-site
npm run build
npm start
```

http://127.0.0.1:4173/ 에서 확인합니다. `dist/index.html`을 직접 열어도 메뉴와 페이지 이동이 동작합니다.

## 내용 수정

- `service-details.mjs`: 9개 세부 서비스의 대상 상황, 수행 범위, 결과물, 페이지별 진행 절차와 FAQ.
- `company-page.mjs`: 회사 소개 및 서비스 상세 페이지의 공통 구성.
- `dist/assets/detail-pages.css`: 메인과 연결되는 상세 페이지 색상, 폰트, 여백 및 반응형 디자인.

- `content.json`: 회사 정보, 세 서비스 영역, 열두 개 세부 서비스의 제목·소개·키워드. 수정 후 `npm run build`로 반영합니다.
- `build.mjs`: 페이지 공통 구조와 메인 상단·회사 소개 문구.
- `home-sections.mjs`: Theori와 Plainbit 스타일을 참고한 메인 하단 구성과 문구.
- `intro.mjs`: 어두운 단색 배경의 A/B/C 스플래시. 업력 36년, 누적 사고조사·복구 서비스 200,000건 이상을 카운트업하며 4초 후 같은 메인으로 전환됩니다.
- `dist/splash-previews.html`: 세 안을 비교하고 재생할 수 있는 미리보기 페이지.
- `dist/assets/intro.css`, `splash.js`: 각 안의 디자인, 카운트업, 화면 유지·재생, 투명한 메인 메뉴와 호버·스크롤 색상 전환.
- `dist/assets/intro-boot.js`: `.html` 유무에 관계없이 미리보기 진입 시 재생합니다. 저장소 접근이 차단돼도 동작하며, 화면이 실제 표시된 이후부터 재생 시간을 계산합니다. CSS와 JS는 내용별 버전 주소를 사용합니다.
- 재생 오류 회귀 확인: `node tests/intro-boot.test.mjs`.
- `dist/assets/style.css`: 공통 디자인과 반응형 레이아웃.
- `dist/assets/app.js`: 모바일 메뉴와 상담 안내 대화상자.

## 초안 범위

서비스별 짧은 소개와 공통 진행 흐름은 구성 확인을 위한 임시 문구이며, 최종 서비스 범위와 세부 수행 절차를 확정한 내용이 아닙니다. 제품명과 기능은 사용자가 제공한 소개자료를 기준으로 추가했으며, 제품별 개발사·버전·지원 조건을 구분했습니다. 미제공 성과 수치나 고객 로고는 추가하지 않았습니다. 상담 버튼은 기존 홈페이지의 대표번호와 운영시간을 안내합니다. 온라인 문의 접수 기능은 없습니다.

2026-10-03 공식 연혁과 사용자 승인 기준에 맞춰 SINCE 1990, 2026년 기준 업력 36년으로 통일했습니다. 누적 20만 건 이상은 사용자가 제공한 사고조사·복구 서비스 합산 수치이며 고객 수가 아닙니다. 전국망은 청주 본사를 포함한 9개 직영 접수망입니다. 공통 실적은 `company-facts.mjs`에서 관리합니다.

회사명, 회사 개요, 연락처, 기존 이미지 출처: https://mdfc-myung.co.kr/default/ 및 회사 개요 페이지. 메인 상단 디자인 참고: https://hmcom.co.kr/ . 메인 하단 디자인 참고: https://theori.io/ko . 이미지 3개는 기존 회사 홈페이지에서 사용 중인 이미지입니다. 웹폰트는 Google Fonts에서 제공되며, 연결할 수 없으면 시스템 글꼴로 표시됩니다.

배포할 때는 `dist` 폴더의 내용을 정적 웹 호스팅에 업로드하면 됩니다.

인트로 타임라인은 수량 추이를 나타내는 통계 그래프가 아니라 1990년부터 2026년까지 이어지는 역사의 시각적 표현입니다. A의 오렌지 색상을 세 안에 적용했으며, 연도·업력·서비스 건수를 함께 진행시킵니다. 메인 하단은 큰 섹션 제목, 실적 소개, 어두운 서비스 영역과 밝은 상세 소개로 Plainbit의 구성을 참고했습니다. https://www.plainbit.co.kr/kr/

디자인 개선 3안은 인트로와 메인의 배경·서체·오렌지·타임라인을 공유하며, 각 안의 카피와 레이아웃이 메인에서도 이어집니다. A: 경험과 신뢰, B: 분석과 대응, C: 중요한 순간의 파트너. `?skip=1`은 미리보기에서도 메인을 바로 표시하고, 재생 버튼은 skip을 제거합니다. 비교 페이지는 인트로·메인 쌍을 함께 표시합니다.

- 영상 원본: `D:/Macro/develop/homepage/명정보기술 홍보영상_홈페이지 자막 5초후 시작 51초.mp4`. 홈페이지용 파일은 `dist/assets/video/mdfc-lab-first-modern-captions-5s.mp4`이며, 승인된 장면 순서와 51.37초 길이를 유지합니다. 영상 자막은 처음 5초 동안 숨기고 일평균 5–9초, 연간 10–14초, 누적 14–19초에 표시합니다. 작은 정자체 산세리프 스타일과 웹용 무음 H.264, 같은 첫 프레임의 포스터 `mdfc-lab-first-modern-poster.jpg`를 사용합니다. 앞선 웹 영상도 비교용 자산으로 보존합니다.
- 기본 영상은 음소거 자동재생입니다. 화면 밖에서 재생 중지, 동작 감소 설정 시 정지 이미지를 제공합니다. 첫 화면에서 스크롤 또는 ‘홈페이지 살펴보기’를 사용하면 기존 메인으로 이동합니다.
- 영상이 실제로 2.5초 재생된 뒤 문구를 표시하고, 4.5초 뒤 스크롤 안내를 표시합니다. 영상 반복 시 재등장 효과를 반복하지 않습니다. 자동재생 불가·영상 오류·동작 감소 설정에서는 문구와 안내를 즉시 표시하며 스크롤과 상단 메뉴는 처음부터 사용할 수 있습니다.
- 데스크톱 동영상 홈페이지는 현재 챕터를 고정한 상태에서 다음 챕터가 위로 올라와 덮는 전환을 사용합니다. 반대 방향에서는 현재 챕터가 내려가며 이전 화면이 드러납니다. 높이가 긴 챕터는 내용을 읽은 뒤 전환하며, 모바일과 동작 감소 설정에서는 일반 스크롤을 유지합니다.
- 2026년 10월 6일: 동영상 첫 화면 대제목은 ‘1990년부터 쌓아온 경험과 국내 최대 분석 인프라로,’와 ‘디지털 증거의 가치를 찾습니다.’ 두 줄로 구성했습니다. 그 아래 ‘디지털포렌식 및 침해사고 전문 기업’, ‘명정보기술 디지털포렌식센터’를 짧은 간격으로 표시합니다. PC 문구는 좌측 상단에 모으고 모바일은 문구 아래 별도 영상 공간을 마련해 영상 장면과 자막을 가리지 않도록 구성했습니다. 재생·소리 버튼을 제거했으며 본 페이지와 상세 페이지의 브라우저 스크롤바는 숨기고 스크롤과 우측 챕터 메뉴는 유지합니다.

- 2026년 10월 6일 실적 자막 위치 조정: 영상 내 Daily average / 100 cases는 1~5초, Annual recovery / over 20,000은 6~10초, Total recovery / over 650,000은 10~15초에 표시합니다. 기존 뒤쪽 자막은 제거했습니다. 수치는 제공 영상의 문구를 그대로 유지하며, 홈페이지의 36년·20만 건 표기와 별도로 원영상의 실적 표기입니다. 이전 영상 파일은 보존하고 새 자산명으로 캐시 혼선을 방지합니다.
