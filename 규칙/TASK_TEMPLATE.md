# 명정보 홈페이지 작업 배정 양식

PM은 아래 내용을 채워 작업 프롬프트에 포함한다. 이 양식 자체는 실제 작업 배정이나 새 세션 실행을 뜻하지 않는다.

```text
작업명:
담당 역할: 구현 / 자산 / 검토 / janiter
작업 목적:
대상 워크트리와 브랜치:
기준 커밋:
읽을 문서: 규칙/README.md 및 연결된 공통 규칙
수정 허용 파일:
참고만 가능한 파일:
공통 인터페이스와 자산 경로:
구현 또는 검토 범위:
완료 기준:
필수 검증:
금지 사항: 타 세션 변경 덮어쓰기, 외부 배포, 유료 사용, 정보 임의 확정
산출물: 변경 파일, 커밋 해시, 검증 결과, 미확정 항목, 차단 사항
보고 경로: PM이 제공한 오르카 dispatch 또는 해당 작업의 보고 절차
```

검토 전담 작업은 발견 사항에 심각도, 파일 위치, 재현 조건과 권장 조치를 포함한다. janiter 작업은 정리 대상별 사용 여부·참조·복구 방법을 포함한다. 역할과 범위는 PM이 작업마다 지정한다.
